# Categories

ASP.NET Core MVC приложение за управление на категории и продукти с Entity Framework Core и SQL Server LocalDB.

## Какво включва

- `Category` с `Id`, `Name` и `DisplayOrder`.
- `Product` с `Id`, `Name` и `IdCategory` като външен ключ към `Category`.
- CRUD страници за категории и продукти, включително избор на категория за продукт.
- Начална страница и падащо меню, което води до страниците на категориите.
- Полупрозрачна навигация с градиентен фон, SVG лого, връзка към началната страница и бутон „Вход“.
- Две миграции: първата създава `Categories`, а втората добавя `Products`.

## Стартиране във Visual Studio

1. Инсталирайте ASP.NET и SQL Server Express LocalDB.
2. Отворете `Categories.sln` във Visual Studio.
3. Изберете профила `http` до зеления бутон за стартиране и натиснете `F5`.
4. При първо стартиране приложението изпълнява EF Core миграциите и създава базата `Categories`.

## Стартиране от терминал

```powershell
dotnet restore
dotnet run --project Categories.csproj
```

За прилагане на миграциите ръчно:

```powershell
dotnet ef database update
```

Клонът `NewBranch` съдържа оформлението от последните стъпки на условието. Бутонът „Вход“ води към демонстрационна страница; приложението няма конфигурирано потребителско удостоверяване.
