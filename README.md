# Categories

Упражнение 2 по Софтуерно инженерство – 12. клас.

ASP.NET Core MVC приложение с категории и продукти и база данни SQL Server.

## Стартиране
1. Отворете `Categories.sln` във Visual Studio 2022.
2. Проверете дали е инсталиран SQL Server LocalDB.
3. Стартирайте проекта. Базата данни се създава чрез EF Core migration.

Клонът `NewBranch` съдържа обновената навигация и оформление от т. 10 на условието.
